# Base-Aware 2D LOS Phase Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development for every implementation step and use adversarial review before moving to GUI workflows.

**Goal:** Implement deterministic 2D LOS analysis on approved canonical layouts: point LOS, base-aware disk approximation, valid base-center checks, firing-lane heatmaps, deployment exposure, terrain contribution metrics, and FastAPI endpoints backed by synthetic fixtures.

**Scope:** This phase does not parse PDFs and does not build the full GUI. It provides the tested backend analysis surface the GUI will call.

---

## LOS Contract

- Board coordinates are inches in the canonical layout coordinate system.
- Terrain blockers are line segments attached to terrain features.
- Point LOS is blocked when the open line between source and target intersects a blocker segment.
- Endpoint contact with a blocker is blocked unless the contact is exactly at the source or target point.
- Base-aware LOS uses a deterministic disk-to-disk approximation: sample boundary and center points for both bases, then report visible if any source-sample to target-sample segment has point LOS.
- Base centers must stay on-board and outside terrain footprints unless a later rules-specific exception is introduced.
- Heatmaps are point-sampled over valid base-center positions and return raw visibility counts plus normalized values.
